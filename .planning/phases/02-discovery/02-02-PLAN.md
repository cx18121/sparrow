**1. `scripts/_lib/apollo-client.ts`** — Apollo API wrapper:

- Import `axios`
- Define and export interface `ApolloPersonResult`:
  ```
  { id: string; first_name: string; last_name: string; name: string;
    email: string | null; title: string; linkedin_url: string | null;
    organization: { name: string; primary_domain: string; } | null; }
  ```

- Export `async function checkApiHealth(apiKey: string): Promise<boolean>`:
  - GET `https://api.apollo.io/v1/auth/health` with header `X-Api-Key: apiKey`
  - Return true if status 200, false on error
  - Log result

- Export `async function searchContacts(domain: string, apiKey: string): Promise<ApolloPersonResult[]>`:
  - POST `https://api.apollo.io/v1/people/search` with body:
    ```json
    { "q_organization_domains": [domain],
      "person_titles": ["CTO", "Founder", "Co-Founder", "CEO", "Head of Engineering", "VP Engineering"],
      "per_page": 10 }
    ```
  - Headers: `{ "X-Api-Key": apiKey, "Content-Type": "application/json" }`
  - Return `response.data.people || []`
  - On 429 (rate limit): log warning, wait 60 seconds, retry once
  - On other error: log and return empty array

- Export `async function enrichContact(email: string, name: string, domain: string, apiKey: string): Promise<ApolloPersonResult | null>`:
  - POST `https://api.apollo.io/v1/people/match` with body `{ email, name, domain }`
  - Headers: `{ "X-Api-Key": apiKey }`
  - Return `response.data.person || null`
  - Log credit consumption warning: "NOTE: /people/match consumes credits"

- Define `WELLFOUND_URL = "https://wellfound.com/companies"`

- Define `async function ingestWellfound()`:
  - Log: `"[SPIKE] Starting Wellfound scraper — this is experimental"`
  - Set a 2-minute timeout for the entire operation
  - Launch browser with stealth: `const browser = await chromium.launch({ headless: true })`
  - Create page, set realistic viewport (1920x1080) and user agent
  - Navigate to WELLFOUND_URL with `waitUntil: "networkidle"`
  - Check for Cloudflare block: look for "challenge" or "captcha" text in page content

  - If not blocked:
    - Try to extract `__NEXT_DATA__` JSON from page: `await page.evaluate(() => window.__NEXT_DATA__)`

    - For each company found:
      - Extract name, website/domain, description, location
      - Call `upsertCompany({...})` with `source: "wellfound"`
    - If __NEXT_DATA__ doesn't exist, fall back to DOM parsing with cheerio (parse company cards)
  - Close browser
  - Log final count or blocked status
  - Disconnect prisma
  - Return `{ status: "success" | "blocked" | "partial", count: number }`

- At bottom: `ingestWellfound().catch(console.error)`

**2. `scripts/poll.ts`** — Polling orchestrator:

- Import `dotenv/config`
- Import `prisma` from `./_lib/prisma.ts`
- Import `ingestYC` from `./ingest-yc.ts`
- Import `enrichApollo` from `./enrich-apollo.ts`
- Import `ingestProductHunt` from `./ingest-producthunt.ts`
- Import `ingestWellfound` from `./ingest-wellfound.ts`

- Read config from env:
  - `POLL_INTERVAL_MS` — default 3600000 (1 hour)
  - `SKIP_WELLFOUND` — default "false" (set to "true" to skip wellfound)
  - `SKIP_PRODUCTHUNT` — default "false"
  - `APOLLO_API_KEY` — required for enrichment, skip enrichment if not set
  - `PRODUCTHUNT_TOKEN` — required for PH, skip if not set
  - `FRESHNESS_HOURS` — default 24 (skip contacts verified within this window)

- Define `async function runPollCycle()`:
  - Log timestamp: `"[POLL] Starting cycle at ${new Date().toISOString()}"`
  - Step 1: Run YC ingestion (always)
    - `try { await ingestYC(); } catch(e) { console.error("[POLL] YC failed:", e.message); }`
  - Step 2: Run Wellfound (unless SKIP_WELLFOUND=true)
    - Same try/catch pattern
  - Step 3: Run Product Hunt (unless SKIP_PRODUCTHUNT=true, or no token)
    - Same try/catch pattern
  - Step 4: Run Apollo enrichment (only if APOLLO_API_KEY set)
    - Before enriching, query contacts where `lastVerifiedAt` is null OR older than `FRESHNESS_HOURS`
    - Log: `"[POLL] ${staleCount} contacts need enrichment"`
    - Run enrichment
  - Log: `"[POLL] Cycle complete at ${new Date().toISOString()}"`

- Define `async function startPolling()`:
  - Log: `"[POLL] Starting with interval ${POLL_INTERVAL_MS}ms"`
  - Run first cycle immediately
  - Set interval to run `runPollCycle` every `POLL_INTERVAL_MS`
  - Handle SIGINT/SIGTERM for graceful shutdown: clear interval, disconnect prisma, exit

- Export `runPollCycle` and `startPolling` as named exports
- At bottom: `startPolling().catch(console.error)`
